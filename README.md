> **On private repos:** these cards only reflect *public* activity by

> itself, not by these badge services. To have the Stats card also include

## Setting Up the Stats & Top Languages Cards

These are generated as static SVGs by [`jstrieb/github-stats`](https://github.com/jstrieb/github-stats),
a GitHub Action that writes `generated/overview.svg` and
`generated/languages.svg` straight into your profile repo — no dependency on
the flaky public Vercel endpoint.

1. In `BinaDev29/BinaDev29`, create `.github/workflows/github-stats.yml`
   with the contents below.
2. (Optional, recommended) Create a
   [personal access token](https://github.com/settings/tokens) with the
   `repo` scope so private repos and full contribution history are counted,
   then add it as a repo secret named `ACCESS_TOKEN`.
3. Commit and push. Trigger it once manually from the Actions tab, or wait
   for the daily schedule.

```yaml
name: generate-stats

on:
  schedule:
    - cron: "30 12 * * *"  # runs once a day
  workflow_dispatch:         # lets you trigger it manually from the Actions tab

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - name: generate stats images
        uses: jstrieb/github-stats@master
        with:
          username: BinaDev29
          # Optional: omit if you didn't add the ACCESS_TOKEN secret
          access_token: ${{ secrets.ACCESS_TOKEN }}
          exclude_repos: BinaDev29/BinaDev29
```

The action commits `generated/overview.svg` and `generated/languages.svg`
back into the `main` branch automatically, matching the `<img>` paths
already in this README.

## Setting Up the Contribution Snake

The animated snake above won't render until you add a small GitHub Action to
your **profile repo** (the repo named exactly `BinaDev29`, same as your
username). One-time setup:

1. In `BinaDev29/BinaDev29`, create the file `.github/workflows/snake.yml`
   with the contents below.
2. Commit and push it to `main`.
3. Go to the **Actions** tab and manually trigger the "generate animation"
   workflow once (it also runs automatically every day at midnight UTC).
4. It will create/update an `output` branch containing the generated SVG —
   the `<img>` tag already added to this README points at that branch, so
   it'll start showing up automatically once the action finishes.

```yaml
name: generate animation

on:
  schedule:
    - cron: "0 0 * * *"   # runs once a day
  workflow_dispatch:        # lets you trigger it manually from the Actions tab

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: generate github-contribution-grid-snake.svg
        uses: Platane/snk@v3
        with:
          github_user_name: BinaDev29
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: push github-contribution-grid-snake.svg to the output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

`<img>` tag in the README for:
