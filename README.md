<details>
<summary><b>⚙️ Setup required — Stats, Top Languages & Snake need one-time GitHub Actions (click to expand)</b></summary>

<br/>

On Dec 27, 2025 the `github-readme-stats` maintainers
[announced](https://github.com/anuraghazra/github-readme-stats/issues/4680#issuecomment-2621841000)
that the public `github-readme-stats.vercel.app` instance is no longer
sponsored and can't reliably run at its old scale — expect it to be down
often, permanently. Their own recommended fix is a maintained **GitHub
Action** that renders the cards and commits them as static SVGs straight
into your profile repo, so nothing depends on that shared endpoint. The
**snake** animation uses the same pattern. **Streak Stats** and **Activity
Graph** are left on their original public services since they were already
rendering fine for you — same fix applies if either ever goes blank.

**1. Stats & Top Languages** — create `.github/workflows/github-stats.yml`:

```yaml
name: Update README cards

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v6

      - name: Generate stats card
        uses: stats-organization/github-readme-stats-action@v2
        with:
          card: stats
          options: "username=BinaDev29&show_icons=true"
          path: profile/stats.svg
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Generate top languages card
        uses: stats-organization/github-readme-stats-action@v2
        with:
          card: top-langs
          options: "username=BinaDev29&layout=compact&langs_count=8"
          path: profile/top-langs.svg
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Commit cards
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "github-actions[bot]@users.noreply.github.com"
          git add profile/*.svg
          git commit -m "Update stats cards" || echo "No changes to commit"
          git push
```

> This is the actively maintained action from `stats-organization`
> (the project `github-readme-stats` development moved to). The default
> `GITHUB_TOKEN` only sees public data; for private repos to count, replace
> it with a [personal access token](https://github.com/settings/tokens)
> (`repo` + `read:user` scopes) added as a repo secret. Commits
> `profile/stats.svg` and `profile/top-langs.svg` to `main`, matching the
> `<img>` paths already in this README.

**2. Contribution snake** — create `.github/workflows/snake.yml`:

```yaml
name: generate animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: BinaDev29
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

> Commits the generated SVGs to an `output` branch, which the `<img>` tag
> above already points at.

After adding either file, push to `main` and trigger it once manually from
the **Actions** tab (or wait for the daily schedule) — the images will
populate automatically once each workflow finishes.
